# AI Visibility Audit — методика Виктора Дрессена

Скилл для Claude: проверяет карточку организации в Яндекс Картах или 2ГИС и оценивает шанс, что её назовут нейросети — Алиса, Нейро Яндекса, ChatGPT, Perplexity, GigaChat.

Автор: **Виктор Дрессен**, руководитель агентства [Яклик](https://yaklik.ru) · Telegram: [t.me/Viktor_Dressen](https://t.me/Viktor_Dressen)

## Что делает

- Собирает данные карточки: рейтинг, отзывы, прайс, особенности, новости, фото.
- Проверяет внешний след: сайт, разметка Schema.org, присутствие в веб-поиске и каталогах.
- Строит **карту из 12 запросов**, которые люди задают нейросетям, и считает, на какую долю из них карточка даёт ответ.
- Сравнивает с 2–3 конкурентами.
- Считает **три индекса** (Яндекс Карты, Алиса/Нейро, ChatGPT/Perplexity) скриптом по единой методике.
- Выдаёт план на 30 дней с оценкой эффекта и трудоёмкости, готовые тексты услуг, FAQ и JSON-LD.
- **Выдаёт результат фирменным PDF** с кликабельными ссылками на Telegram автора и сайт агентства на каждой странице и контактным блоком в конце.

Пример отчёта: [examples/epillevel-report.pdf](examples/epillevel-report.pdf).

## Структура

```
SKILL.md                     — инструкция для Claude
references/scoring.md        — факторы, критерии, веса индексов
references/niche-facts.md    — какие факты ищут нейросети в разных нишах
references/test-queries.md   — протокол ручной проверки в Алисе и ChatGPT
references/schema-template.md — шаблон разметки для сайта
templates/report.md          — шаблон отчёта для клиента
scripts/score.py             — подсчёт индексов
scripts/make_pdf.py          — сборка фирменного PDF из Markdown-отчёта
assets/fonts/                — шрифты DejaVu с кириллицей (свободная лицензия)
examples/                    — пример аудита: JSON, Markdown и PDF
```

Для PDF нужен Python 3 и библиотека `reportlab` (`pip install reportlab`). В claude.ai с включённым выполнением кода она ставится автоматически по инструкции скилла.

## Установка

**claude.ai:** Настройки → Возможности → Скиллы → загрузить ZIP этой папки.
**Claude Code:** скопировать папку в `~/.claude/skills/viktor-dressen-ai-visibility/`.

## Оговорка

Индексы — экспертная оценка по факторам, а не замер реальных ответов нейросетей. Для замера в скилле есть протокол ручной проверки.
