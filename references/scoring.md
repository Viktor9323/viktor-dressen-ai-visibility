# Методика оценки

## Данные для сбора

**Карточка:** название, рубрики (все), адрес + этаж/офис + ориентиры, телефон, сайт, соцсети и мессенджеры, режим работы, рейтинг, число оценок, число отзывов, дата последнего отзыва, аспекты отзывов (% позитива), наличие ответов владельца (и их содержательность), награды («Хорошее место»), «Информация подтверждена владельцем», число фото, число новостей и дата последней, особенности/атрибуты, онлайн-запись, описание организации, акции/спецпредложения.

**Прайс:** число услуг, группировка, цены у всех позиций, качество описаний (факты / шаблон / пусто), упоминание оборудования, методик, брендов, специалистов.

**Внешний след:** сайт (есть/нет, в индексе), прайс на сайте текстом, FAQ, Schema.org, найдено ли в веб-поиске по названию, площадки (2ГИС, Zoon, Yell, Google Maps, отраслевые), совпадение NAP, текстовые посты в VK/Telegram.

## Шаблон JSON для scripts/score.py

Значение каждого фактора — доля от 0 до 1 (1 = полностью выполнено). Ставь по критериям ниже.

```json
{
  "name": "EpilLevel",
  "city": "Одинцово",
  "factors": {
    "rating": 1.0,
    "reviews_volume": 0.8,
    "reviews_specificity": 0.4,
    "owner_replies": 0.6,
    "price_completeness": 1.0,
    "price_facts": 0.1,
    "description": 0.3,
    "features": 0.9,
    "categories": 0.6,
    "posts": 0.3,
    "trust": 1.0,
    "photos": 1.0,
    "website": 0.0,
    "website_content": 0.0,
    "schema": 0.0,
    "web_findable": 0.0,
    "citations": 0.2,
    "nap": 0.5,
    "social_text": 0.4,
    "query_coverage": 0.35
  }
}
```

## Критерии

| Фактор | 1.0 | 0.5 | 0 |
|---|---|---|---|
| rating | ≥4.8 и ≥50 оценок | 4.5–4.7 или 15–49 оценок | <4.3 или <10 оценок |
| reviews_volume | ≥50 и свежий отзыв за 30 дней | 15–49 или последний >60 дней | <10 |
| reviews_specificity | большинство с услугой/результатом/районом | треть с конкретикой | «всё супер» |
| owner_replies | на все, содержательно, с упоминанием услуги | частично или шаблонно | нет |
| price_completeness | все услуги с ценами | часть без цен | прайса нет |
| price_facts | факты (время, курс, метод, оборудование, кому) | частично | шаблон/ключи/пусто |
| description | факты + ориентиры + оборудование + специалисты | общие слова | пусто |
| features | все релевантные атрибуты | половина | почти пусто |
| categories | основная + все реальные доп. рубрики | только основная, есть подходящие доп. | неверная рубрика |
| posts | ≥1 в неделю, экспертные | редкие или только акции | 0–2 |
| trust | подтверждено владельцем + награда | одно из двух | ничего |
| photos | ≥30, интерьер/работы/оборудование/команда | 10–29 | <10 |
| website | свой сайт, в индексе, ссылка в карточке | есть только таплинк/соцсеть | нет |
| website_content | прайс текстом, FAQ, адрес, оборудование | частично | нет сайта/всё картинками |
| schema | LocalBusiness + Offer/FAQ | только LocalBusiness | нет |
| web_findable | находится по названию + городу | находится только карточка-агрегатор | не находится |
| citations | ≥4 площадки | 2–3 | 0–1 |
| nap | везде одинаково | мелкие расхождения | противоречия |
| social_text | регулярные текстовые посты с услугами и городом | редкие | нет/только картинки |
| query_coverage | = покрытие карты запросов (✅=1, ⚠️=0.5, ❌=0) / 12 | | |

## Веса индексов

**Индекс «Карты»** (насколько карточка сильна в самих Яндекс Картах): rating 20, reviews_volume 15, reviews_specificity 5, owner_replies 10, price_completeness 10, price_facts 5, description 5, features 5, categories 10, posts 5, trust 5, photos 5.

**Индекс «Алиса / Нейро»:** rating 12, reviews_volume 8, reviews_specificity 10, owner_replies 4, price_completeness 8, price_facts 14, description 8, features 5, categories 6, posts 8, trust 7, query_coverage 10.

**Индекс «ChatGPT / Perplexity»:** website 25, website_content 15, schema 10, web_findable 15, citations 15, nap 5, social_text 5, query_coverage 10. **Ограничение:** если website = 0, индекс не выше 30.

Шкала 0–10 = баллы / 10, округление до целого.

Интерпретация: 0–3 — нейросеть почти не назовёт; 4–6 — назовёт иногда, в общих запросах; 7–8 — хорошие шансы; 9–10 — сильный кандидат в рекомендации.
